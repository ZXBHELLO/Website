# ImageGlass轻量级开源图片查看器

在日常 Windows 使用中，系统自带的"照片"应用在格式兼容性、打开速度与资源占用上常显捉襟见肘，尤其面对 RAW、HEIC、WEBP、PSD 等现代图像格式时，往往需要额外安装解码器或依赖重型软件才能查看。ImageGlass 是一款基于 GPL-3.0 协议开源的轻量级图片查看器，定位即作为 Windows 原生看图工具的现代化替代方案，以极小的体积极高的效率完成日常图片浏览、格式转换与基础编辑工作。

![ImageGlass](/assets/software/imageglass.png)

## 一、ImageGlass 简介

ImageGlass 由越南开发者 Phap Duong 发起并维护，项目托管于 GitHub，遵循 GPL-3.0 开源协议，是一款完全免费、无广告、无遥测的桌面软件。它的核心目标是提供一个"打开即看、格式通吃、操作高效"的图片查看器，弥补 Windows 系统原生工具在现代图像格式支持与浏览体验上的不足。

从定位上看，ImageGlass 不追求成为 Photoshop 式的全功能图像编辑器，而是聚焦于"看图"这一高频场景：在保证轻量化的前提下，尽可能扩展格式兼容范围，并配套批量处理、幻灯片、主题自定义等围绕浏览效率展开的辅助能力。对于需要在大量图片之间快速切换、比对的用户而言，这种聚焦型工具往往比综合性图像软件更顺手。

## 二、主要功能特点

### 1. 80+ 格式支持

ImageGlass 原生支持 80 多种图像格式，覆盖范围远超 Windows 自带工具。常见格式如 JPG、PNG、GIF、BMP、TIFF、WEBP、SVG 自不必说，更值得关注的是对以下现代与专业格式的支持：

* **HEIC / HEIF**：iPhone 默认拍摄格式，Windows 原生需额外扩展才能打开
* **JXL（JPEG XL）**：新一代高压缩比图像格式
* **RAW**：覆盖多家相机厂商的原始文件（CR2、NEF、ARW、DNG 等）
* **PSD**：Photoshop 源文件，可在未安装 Photoshop 的情况下直接预览
* **AI / EPS**：部分矢量与排版文件可通过内嵌预览方式查看

无需逐个安装解码器，ImageGlass 在安装阶段已集成所需依赖，开箱即用。

### 2. 轻量快速

安装包体积控制在较小范围，启动几乎瞬时，内存与 CPU 占用均处于低位。即便在高分辨率大尺寸图片之间连续切换，也能保持流畅响应，不会出现卡顿或长时间等待的情况。这一特性使其非常适合在配置一般的办公电脑或老旧设备上作为主力看图工具使用。

### 3. 现代化界面

UI 采用简洁直观的布局，主区域为图像显示区，顶部与侧边为工具栏，关键操作触手可及。界面支持深色与浅色主题切换，适配不同工作环境与个人偏好，长时间观看图片时也可减轻视觉疲劳。

### 4. 批量处理

针对需要一次性处理大量图片的场景，ImageGlass 提供三项核心批量能力：

* **批量重命名**：按命名规则统一调整文件名，支持序号、日期等变量
* **批量格式转换**：将整批图片统一转换为指定格式（如 RAW 转 JPG、HEIC 转 PNG）
* **批量调整尺寸**：按比例或目标分辨率统一缩放，适合生成缩略图或适配发布平台

### 5. 图像编辑

内置基础编辑功能，避免为小改动额外打开专业软件：

* 裁剪与旋转
* 色彩调整（亮度、对比度、饱和度等）
* 添加水印

这些功能不追求专业级精度，但足以满足快速修图、社交分享前的轻处理需求。

### 6. 幻灯片播放

支持全屏幻灯片浏览模式，可自定义切换间隔时间，适合集中查看一组照片或做简易演示。播放过程中支持手动前进、暂停与退出，操作逻辑直观。

### 7. 主题自定义

除深浅主题切换外，ImageGlass 还允许用户进一步个性化外观：

* 自定义工具栏布局
* 替换图标包
* 调整配色方案

对于重视视觉一致性或喜欢折腾界面的用户，这一层开放性提供了较高的可玩性。

### 8. 快捷键操作

完善的快捷键体系是 ImageGlass 高效浏览的关键。常见操作如上一张/下一张、缩放、旋转、全屏、幻灯片等均有对应快捷键，熟练掌握后可在不触碰鼠标的情况下完成绝大多数浏览动作，显著提升查看效率。

## 三、适用场景

### 1. 摄影师浏览 RAW

摄影师在拍摄后常需快速筛选素材，但 RAW 文件体积大、格式多样，Windows 原生工具难以直接打开。ImageGlass 对多种 RAW 格式的原生支持使其成为轻量级筛选工具：无需启动 Lightroom 或 Capture One，即可快速翻看素材、判断取景与曝光，再决定哪些文件值得进一步精修。

### 2. 设计师查看多格式

设计师日常工作涉及 PSD、AI、SVG、PNG、WEBP 等多种格式，频繁切换专业软件查看预览效率低下。ImageGlass 可在不依赖原作者软件的前提下直接预览这些文件，尤其适合在素材库中快速定位、比对版本。

### 3. 日常看图

对于普通用户，ImageGlass 同样是替代 Windows 照片的理想选择：开机即用、打开即看，支持 GIF 动图、HEIC 手机照片、WEBP 网页图片等常见格式，免去了"格式不支持"的困扰。配合批量转换功能，还可将手机导出的 HEIC 照片统一转为 JPG 以便分享。

### 4. 技术文档与截图管理

从事技术写作或文档维护的用户，常需查看大量截图、流程图、SVG 图标。ImageGlass 对 SVG 的良好支持使其可作为矢量素材的快速预览器，配合快捷键翻看，效率远高于逐个打开浏览器查看。

## 四、安装与基础使用

### 1. 下载安装

1. 访问官网 <https://imageglass.org> 或 GitHub 仓库 <https://github.com/d2phap/ImageGlass>
2. 在 Releases 页面选择对应版本（通常提供安装版与便携版两种形式）
3. 下载安装包后运行，按向导完成安装；若选择便携版，解压即可使用，无需写入系统注册表

### 2. 首次配置

首次启动 ImageGlass 时，建议完成以下基础配置：

* **关联文件格式**：在设置中选择需要 ImageGlass 默认打开的扩展名，建议至少勾选 JPG、PNG、GIF、WEBP、HEIC、SVG 等常用格式，以便双击即用 ImageGlass 打开
* **选择主题**：根据环境光线选择深色或浅色主题
* **设置默认查看模式**：可配置启动时是否自动适应窗口大小、是否显示工具栏等

### 3. 基础操作

* 双击图片文件或拖入 ImageGlass 窗口即可打开
* 使用左右方向键或滚轮在当前目录的图片之间切换
* 滚轮缩放、快捷键旋转与全屏切换
* 通过菜单或快捷键进入幻灯片模式

## 五、使用技巧

### 1. 主题切换

在设置菜单中可一键切换深色与浅色主题；若希望进一步个性化，可下载社区提供的图标包与配色方案，替换默认外观，打造与工作环境一致的视觉风格。

### 2. 快捷键进阶

掌握以下高频快捷键可大幅提升浏览效率：

* 上一张 / 下一张：方向键左右
* 缩放：`Ctrl` + 滚轮 或对应数字键
* 旋转：通常绑定至方向键上下或自定义组合键
* 全屏：`F11` 或菜单指定
* 幻灯片：菜单或快捷键启动，配合间隔设置自动播放

建议在设置中查看完整快捷键列表，并按个人习惯调整。

### 3. 批量转换

批量转换是 ImageGlass 的高价值功能之一，典型用法如下：

1. 在文件列表中选中需要转换的多张图片
2. 进入批量转换菜单，选择目标格式（如 JPG、PNG、WEBP）
3. 按需设置输出质量、尺寸缩放规则
4. 指定输出目录并执行

对于摄影师而言，这一流程可快速将 RAW 筛选结果转为 JPG 交付；对于普通用户，则可将 HEIC 批量转为通用格式以便分享。

### 4. 扩展格式支持

ImageGlass 本身已内置丰富格式支持，若遇到个别冷门格式无法打开，可通过以下方式扩展：

* 在设置中检查并启用额外的图像编解码插件
* 关注官方 Release Notes，新版本常会追加对新格式的支持
* 对于特别冷门的格式，可在社区 issue 中反馈需求
