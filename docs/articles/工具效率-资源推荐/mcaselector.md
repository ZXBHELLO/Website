# MCA Selector Minecraft存档区块管理工具

随着 Minecraft Java 版世界探索范围不断扩大，存档文件体积膨胀、加载缓慢、区块冗余等问题会逐渐显现，尤其是长期运行的服务器或已积累数千区块的单人世界，常常面临存档臃肿与性能下降的双重压力。MCA Selector 是一款开源的 Minecraft Java 版世界存档区块管理工具，以地图可视化方式呈现整个世界的区块结构，并提供选择、删除、导出、导入、NBT 编辑等完整操作链路，使管理员与玩家能够精确地对存档进行瘦身、迁移与修复，而无需依赖游戏内命令或世界编辑器的复杂流程。

![MCA Selector](/assets/software/mcaselector.png)

## 一、MCA Selector 简介

MCA Selector 由社区开发者 cassiofb-dev 维护（较早版本由 11324266 维护），项目托管于 GitHub，遵循 MIT 开源协议，基于 Java 构建，可运行于 Windows、macOS、Linux 三大主流桌面平台。其命名中的 MCA 对应 Minecraft 存档所采用的 Anvil 文件格式（.mca），即 Region 文件，工具的核心职责正是围绕这一层级的区块数据进行管理。

从定位上看，MCA Selector 并不替代游戏内的创造模式或 WorldEdit 等方块级编辑工具，而是聚焦于"区块级"的宏观管理：当存档因为远距离探索、维度碎片、测试区域或损坏区块而变得臃肿时，它能以可视化的方式快速定位问题区域，并通过框选、过滤等手段批量处理，从而在不影响主体存档的前提下完成瘦身与优化。对于服务器运维人员而言，这类工具几乎是周期性存档维护的必备环节。

## 二、主要功能特点

### 1. 区块可视化选择

MCA Selector 会读取世界存档目录下的 Region 文件，将所有区块以地图块的形式渲染到主界面，用户可以通过鼠标滚轮缩放、拖拽平移来浏览整个世界。在选择层面，工具支持矩形框选、点选、多区域叠加选择等多种方式，选中后的区块会高亮显示，便于确认范围后再执行后续操作。这种可视化交互大幅降低了"按坐标定位区块"的认知成本，尤其适合处理跨多个 Region 的大范围区域。

### 2. 区块删除

删除是 MCA Selector 最核心的维护能力之一。选中目标区块后，可一键将其从存档中移除，对应的 Region 文件会被原地更新。该功能常用于清理远距离探索产生的无意义区块、测试用临时区域、损坏或冗余的维度区块，从而有效减小存档体积、降低加载时的内存压力，并改善服务器启动与玩家进入世界的响应速度。

### 3. 区块导出与导入

工具支持将选中的区块导出为独立的区块文件，并可在其他世界中导入这些文件，实现存档片段的迁移。这一能力使得"把 A 世界的某个建筑搬到 B 世界"不再依赖复杂的命令方块或第三方脚本，而是以区块为单位整体搬运，保留了原区域的地形、方块、实体与方块实体数据。导入时还支持坐标偏移，便于将迁移区块放置到目标世界的合适位置。

### 4. 区块过滤

MCA Selector 内置了一套基于条件的区块筛选机制，可依据区块坐标范围、Minecraft 版本、最后更新时间、NBT 数据字段等多种维度组合过滤。例如，可以筛选出"所有版本低于 1.18 的区块"或"位于特定坐标矩形之外的所有区块"，再统一执行删除或导出。对于需要批量处理大量区块的服务器存档，过滤功能相比手动框选更加精确且高效。

### 5. NBT 编辑

每个区块的底层数据以 NBT（Named Binary Tag）格式存储，包含方块状态、生物群系、实体、方块实体、光照与高度信息等。MCA Selector 提供了 NBT 查看与编辑界面，用户可以展开区块的 NBT 树，查看并修改其中的字段。这一能力适合用于修复损坏区块、调整特定方块的属性、清理异常实体或排查存档异常。需要强调的是，NBT 编辑属于底层操作，错误的修改可能导致区块加载失败或数据损坏，操作前务必备份原始存档。

### 6. 区域编辑

除区块级别外，MCA Selector 还支持 Region（区域，32x32 区块）级别的整体操作，包括整区域的导入与导出。当需要搬运较大范围的地形或对整个区域进行备份时，以 Region 为单位处理比逐区块操作效率更高，且能保持区域内部的数据完整性。

### 7. 复制粘贴

工具提供区块级别的复制与粘贴功能，可在同一世界内或跨世界复制选中区块，并粘贴到指定坐标。该能力与导入导出类似，但更侧重于即时操作场景，例如在同一个世界内将一片建筑复制到另一处作为备份或镜像，而不必经过文件中转流程。

### 8. 图像生成

MCA Selector 可将整个世界或选中区域渲染为整体地图图像，导出为 PNG 等常见格式。这一功能既可用于存档的视觉备份，也适合生成世界全景图用于展示、规划或归档。渲染时支持调整缩放级别与输出分辨率，以平衡图像清晰度与文件体积。

### 9. 缓存机制

为提升二次浏览的流畅度，工具会对区块图像进行缓存。首次打开世界时需要逐区块渲染，耗时相对较长；而缓存命中后再次浏览同一区域时，加载速度显著提升。缓存可按需清理，避免在频繁切换不同世界时占用过多磁盘空间。

### 10. 多版本支持

MCA Selector 兼容多个 Minecraft Java 版本的存档格式，能够识别不同版本间的 Anvil 格式差异、数据版本号与字段变化，在读取与写入时进行相应处理。这意味着同一工具即可管理 1.12、1.16、1.18、1.20 等不同时期的世界存档，降低了版本切换带来的工具维护成本。

## 三、适用场景

### 1. 存档瘦身优化

长期运行的世界会因探索、传送、随机生成而产生大量边缘区块，存档体积动辄数 GB 甚至更大。通过 MCA Selector 的可视化选择与过滤功能，可快速定位并删除距离主城过远、无实际价值的区块，显著减小存档体积，提升服务器启动速度与玩家进入世界的加载效率。

### 2. 建筑迁移

当需要将某个建筑或区域从一个世界迁移到另一个世界（例如从单人存档迁移到服务器、从旧版本世界迁移到新版本世界）时，可使用导出与导入功能以区块为单位整体搬运，保留地形与方块实体的完整性，避免手动重建。

### 3. 世界备份

对关键区域或整个世界进行周期性备份是运维的基本要求。借助 Region 级别的导出能力，可将重要区域保存为独立文件，在发生误操作或存档损坏时快速回滚，而无需恢复整个世界存档。

### 4. 区块修复

部分区块可能因异常退出、版本升级或第三方工具误操作而损坏，表现为加载失败、黑块、实体异常等。通过 NBT 编辑功能可查看问题区块的底层数据，定位异常字段并手动修复，或直接删除损坏区块让游戏重新生成，从而恢复世界的可玩性。

### 5. 服务器存档管理

服务器管理员需要对多个世界的存档进行周期性维护，包括清理无用区块、备份核心区域、迁移建筑、生成世界预览图等。MCA Selector 的命令行（Headless）模式特别适合集成到自动化运维脚本中，在停机维护窗口批量执行区块处理任务，降低人工介入成本。

## 四、安装与基础使用

### 1. 下载与安装

1. 访问 GitHub 仓库 [https://github.com/cassiofb-dev/mcaselector](https://github.com/cassiofb-dev/mcaselector)（较早版本可参考 [https://github.com/11324266/mcaselector](https://github.com/11324266/mcaselector)）
2. 进入 Releases 页面，根据操作系统选择对应安装包：Windows 选择 exe 或 zip 版本，macOS 选择 dmg 或 zip 版本，Linux 选择对应的发行包或 jar 包
3. 由于工具基于 Java 构建，运行前需确保系统已安装合适版本的 Java 运行环境（JRE/JDK），具体版本要求以 Release 说明为准
4. 安装版按向导完成安装；便携版解压即可运行；若使用 jar 包，可通过 `java -jar mcaselector.jar` 命令启动

### 2. 打开存档目录

启动后，通过菜单或工具栏选择"打开世界"或类似入口，定位到 Minecraft 存档目录。Java 版默认存档目录通常位于：

- Windows：`%APPDATA%\.minecraft\saves\世界名`
- macOS：`~/Library/Application Support/minecraft/saves/世界名`
- Linux：`~/.minecraft/saves/世界名`

服务器存档则位于服务端根目录下对应的世界文件夹。选择世界目录后，工具会开始读取 Region 文件并渲染区块地图。

### 3. 基础选择与删除流程

1. 使用滚轮缩放至合适的视野层级，拖拽平移到目标区域
2. 使用鼠标框选需要处理的区块，选中区域会高亮显示
3. 在工具栏或右键菜单中选择"删除"等操作，确认后执行
4. 操作完成后，建议在游戏内重新加载世界以验证结果

需要特别强调：任何删除、修改操作执行前，务必关闭正在运行的游戏或服务器，并完整备份原始存档目录，避免不可逆的数据损失。

## 五、使用技巧与注意事项

### 1. 操作前务必备份存档

这是使用 MCA Selector 最重要的一条原则。区块删除、NBT 编辑、导入导出等操作均会直接修改存档文件，一旦误操作难以恢复。建议在每次维护前，将整个世界目录完整复制到独立的备份位置，确认操作无误后再清理备份。

### 2. 区块坐标定位

MCA Selector 界面中会显示当前鼠标位置对应的区块坐标与方块坐标，结合 F3 调试屏幕中获取的游戏内坐标，可精确对应到具体区块。对于需要按已知坐标定位区域的任务，建议先记录目标坐标范围，再在工具中通过过滤或手动框选精确选中。

### 3. NBT 编辑谨慎操作

NBT 数据是区块的底层结构，字段含义与 Minecraft 版本强相关。编辑前应充分了解字段语义，避免随意修改未知字段。对于不确定的修改，建议先导出当前区块作为回滚点，逐步调整并在游戏内验证，切忌一次性大范围改动。

### 4. 版本兼容性

不同 Minecraft 版本的存档格式存在差异，尤其是 1.13 扁平化、1.18 世界高度扩展等版本节点带来了较大的数据结构变化。使用 MCA Selector 时应选择与存档版本兼容的工具版本，跨版本导入导出区块时需格外谨慎，避免因字段缺失或格式不一致导致目标世界加载异常。

### 5. Headless 命令行模式

MCA Selector 提供 Headless 模式，允许在无图形界面的服务器环境中通过命令行执行区块处理任务，适合集成到自动化脚本中。常见用法包括批量删除指定坐标范围的区块、导出区域、生成世界预览图等。使用前应查阅仓库中关于命令行参数的文档，确认参数语义与输出路径，建议先在测试存档上验证命令行为，再应用到生产存档。
